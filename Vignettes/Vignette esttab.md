# <center> Export Tables using Esttab </center>

This vignette demonstrates how to export tables produced by **did_multiplegt_stat** using **estout** and its companion commands. 
All outputs from **did_multiplegt_stat** are stored in b() and V(). When the command is executed without the options **by_fd** or **by_baseline**,
using **esttout** is straightforward. In this vignette, we first show how to export tables when the command is run without these two options
and then provide tips for exporting tables when the options are used.
